Experience

Research Assistant, Durham College AI Hub · May 2026 to present

Working at the AI Hub has been an awesome hands-on experience. I built the agentic core of an AI assistant that switches between several personas, powered by AWS Lambda and Amazon Bedrock. It remembers context across turns and stays under 1.8 seconds at the 95th percentile in load tests.

To make sure the assistant actually knows what it’s talking about, I set up retrieval from the client’s own documents using Bedrock Knowledge Bases and Titan embeddings.

I also tracked down and fixed a sneaky routing bug where rejected requests were still reaching the LLM. Catching that saved about 1.4K tokens per request and prevented unnecessary cloud costs from running up.

The coolest part was redesigning our intent routing: instead of running three classifiers in a slow sequence, I rebuilt it with TypeSafe’s Jev decision model in one parallel call. Median latency crashed from 3.8 s to 0.14 s (about 29x faster!) while holding recall at 93.9% across six intents.

Financial News Agent

Python, TypeScript, FastAPI, Claude API, Supabase, SvelteKit

I wanted to see how far I could push Claude’s tool-calling capabilities to build a real-time financial analyst. The agent breaks down complex user queries, autonomously decides which tools to trigger (fetching live stock quotes, market news, company financials, or insider trades), and synthesizes everything into a clear, cited answer.

To make it feel super responsive, I built a SvelteKit frontend that streams the response live and visualizes tool-call progress as it happens. The FastAPI backend handles the heavy lifting, locked down with Supabase JWT auth, row-level security, per-IP rate limits, and input sanitization.

Vision Transformer Research

Python, PyTorch, Scikit-learn, Pandas

Medical imaging has always fascinated me because getting it right actually matters. This project was also me and my classmate Rey’s first real dive into research. We teamed up to evaluate over eight vision architectures, including DINOv2, ViT, SwinV2, ResNet, and YOLO, on binary skin cancer classification using stratified 5-fold cross-validation.

Garbage in means garbage out, so we curated and cleaned the noisy MRA-MIDAS dataset from 3,000 cases down to 906 quality-controlled samples, building reproducible preprocessing and augmentation pipelines from scratch.

Through ablation studies, targeted layer-freezing, and building ensembles, we pushed the top configuration to ~92% sensitivity at a clinically relevant threshold.

Temperature Modelling

Python, XGBoost, FastAPI, Streamlit, GCP, Docker

I built this to take tabular machine learning all the way from raw weather history into a deployed, production-ready microservice. Using XGBoost with regularization and 10-fold randomized search tuning to keep it from overfitting, the model hit an R² of 0.991 and MAE of 0.71.

To turn it into something anyone could easily query, I wrapped the inference pipeline in a Dockerized FastAPI service on Google Cloud Run and built a clean Streamlit interface for on-demand predictions.

LotWatch

Python, OpenCV, NumPy, Jupyter

LotWatch is a real-time computer vision system that monitors parking lot footage to figure out which spaces are taken versus empty, frame by frame. It renders an annotated video stream complete with live green/red overlays and an occupancy counter.

Instead of throwing a heavy deep net at the problem, I wanted an efficient classical CV approach: each space is a hand-drawn polygon combining MOG2 background subtraction with Laplacian edge-texture filtering, leveraging the fact that cars pack far more high-frequency edges than asphalt. Adjustable thresholds keep it accurate even with solid-color cars or shifting daylight.
